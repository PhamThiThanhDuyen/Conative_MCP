# Pilot Flow Demo

Use this folder to store a runnable example of the Conative QE flow:

1. Requirement excerpt
2. Risk Map
3. Testcase Matrix
4. API Verification Report
5. Evidence Package
6. Residual Risk Assessment
7. Go / No-Go Report

Recommended demo case:

- Pick one real Conative feature or API scope.
- Keep data synthetic and sanitized.
- Show one Passed case, one Failed case, one Blocked assumption, and one residual risk.
- Run validators before presenting artifacts.

Expected demo output files:

- `01-requirement.md`
- `02-risk-map.md`
- `03-testcase-matrix.md`
- `04-api-verification-report.md`
- `05-evidence-package.md`
- `06-residual-risk-assessment.md`
- `07-go-no-go-report.md`
