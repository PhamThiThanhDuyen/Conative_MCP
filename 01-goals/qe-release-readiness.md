# Goal: qe-release-readiness

## Outcome
Tạo bộ artifact đủ để QA đưa ra đề xuất Go/No-Go cho một requirement hoặc release scope.

## Calls skills
1. analyze-requirement-risk
2. testcase-matrix-design
3. assess-data-readiness (when data is in scope)
4. qa-api-verification (when an API is in scope)
5. verify-data-quality (when data is in scope)
6. api-data-ui-verification (when a UI is in scope)
7. evidence-package
8. residual-risk-assessment
9. go-no-go-report

## Required outputs
- Requirement Gap Register
- Business Risk Map
- Testcase Matrix
- Data Readiness Assessment (when data is in scope)
- API Verification Report
- Data Verification Report (when data is in scope)
- Evidence Package
- Residual Risk Assessment
- Go/No-Go Report

## Human gates
- QA xác nhận assumption.
- QA duyệt risk priority.
- QA kiểm tra evidence.
- QA chịu trách nhiệm release recommendation.
