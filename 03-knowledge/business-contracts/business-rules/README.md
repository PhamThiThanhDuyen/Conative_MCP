# Business Rules

Store approved product behavior here: calculations, workflows, permissions,
thresholds, state transitions, and error handling expectations.

## Usage

- Test cases can be `Ready` only when expected business behavior maps to a rule or approved requirement.
- If a business rule is missing, create an Open Question and mark affected cases blocked.
