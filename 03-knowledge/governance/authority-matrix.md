# Authority Matrix

| Decision | Primary authority | Supporting evidence | Must not decide alone |
|---|---|---|---|
| Expected behavior for a target release | Approved BA/PO business contract | API expectation, design, current product | Current implementation or industry convention |
| Current production behavior | Verified product docs or scoped runtime evidence | Deployed API spec, logs, screenshots | Draft requirement or roadmap |
| Industry risk or requirement gap | Approved domain source or domain expert | Current product and business contract | Generic benchmark guidance |
| QA execution method | QA standards | Heuristics and evidence samples | Product docs |
| Known accepted deviation | Approved known-issue record | Defect and release evidence | Informal statement |
| Release recommendation | Release-decision standard plus current evidence | Contracts, risks, known issues | A single test result or unapproved assumption |

Authority always remains limited by document scope, status, target release,
client or tenant, role, environment, and verification date.
