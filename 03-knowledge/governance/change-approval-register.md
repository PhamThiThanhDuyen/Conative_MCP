# Skill And Knowledge Approval Register

Add one row only after the required checks and human reviews are complete. A
blank register does not imply that existing content is rejected; it means its
approval evidence has not yet been migrated into this register.

| Approval ID | Item type | Stable ID / path | Change class | Decision | Scope / authority | Checks and evaluation | Reviewer(s) | Approved at | Evidence / conditions |
|---|---|---|---|---|---|---|---|---|---|

## Decision Values

- `Approved`
- `Approved with Conditions`
- `Rejected`
- `Superseded`

Use an immutable approval ID such as `APR-YYYYMMDD-NNN`. For a later semantic
change, create a new record and reference the earlier approval instead of
overwriting decision history.
