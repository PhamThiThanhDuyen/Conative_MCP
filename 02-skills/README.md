# Quality Engineering Capabilities

| Capability | Skills |
|---|---|
| Requirement Engineering | `analyze-requirement-risk` |
| Test Design | `testcase-matrix-design`, `automation-from-testcases`, `spreadsheet-test-execution` |
| API Verification | `qa-api-verification` |
| Data Readiness Assessment | `assess-data-readiness` |
| Data Verification | `verify-data-quality` |
| UI Verification | `api-data-ui-verification` |
| Evidence & Diagnosis | `evidence-package` |
| Release Intelligence | `residual-risk-assessment`, `go-no-go-report` |

Capabilities express stable Quality Engineering outcomes. Skills remain small,
composable procedures that consume governed knowledge and always produce an
artifact. Automation is an execution method within Test Design rather than a
separate business capability.

## Change Approval

Before creating, updating, installing, or publishing a Skill, follow
`03-knowledge/governance/change-approval-policy.md`. Keep OpenAI Skill
frontmatter limited to supported metadata; record approval status and evidence
in `03-knowledge/governance/change-approval-register.md`.
